# Heartland Accessibility

Healthcare website accessibility consulting site built with **Next.js**, **React**, and **Tailwind CSS**, targeting **WCAG 2.1 Level AA**.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build
- `npm run lint` — ESLint

## Accessibility features

- Skip link to main content
- Landmark regions and semantic headings
- Keyboard-accessible mobile navigation (Escape to close)
- Visible `:focus-visible` outlines
- Form validation with `aria-invalid`, `aria-describedby`, and live regions
- `prefers-reduced-motion` support
- Accessibility statement at `/accessibility-statement`
